# Book Management System

## 项目简介

一个基于 WPF 的本地电子书管理软件，用于整理和分类电子书文件。

## 功能

* 📚 图书导入与扫描
* 🗂 分类管理（PDF / EPUB / TXT）
* 🖼 封面显示
* 🔍 快速查找图书
* 📊 阅读进度记录

## 技术栈

* C#
* WPF（MVVM架构）
* SQLite（本地数据存储）

## 项目结构

* Models：数据模型
* ViewModels：业务逻辑
* Views：界面
* Services：服务层
* Repositories：数据访问

## 运行方法

1. 使用 Visual Studio 打开 `BookShelfApp.sln`
2. 编译运行

## 项目说明

该项目为个人练习项目，用于学习 WPF 和软件架构设计
